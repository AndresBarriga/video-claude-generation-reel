# Resultados (vista legible; los datos están en `datos/publicados.csv`)

## Cómo se mide
- **Una fila por medición** en el CSV (vídeo + momento). Medir a **48 h** y a **7 días**; las mediciones intermedias se apuntan si las hay. Comparar siempre la misma ventana.
- Andrés manda capturas o grabación de «Reel insights»; Claude rellena el CSV y actualiza esta tabla.

## Métricas (varias; cada una responde a una pregunta)
| Pregunta | Métrica | Uso |
|---|---|---|
| ¿Cuánto alcance? | vistas | Un viral vale aunque convierta poco: trae seguidores en bruto |
| ¿Cuánto hace crecer la cuenta? | **seguidores por vídeo** (mediana a 7 d) | Criterio principal del test humor vs historias |
| ¿Convierte quien lo ve? | seguidores / 1.000 vistas · visitas al perfil / 1.000 · visita → seguir | Diagnóstico: contenido (visitas) vs perfil/cuadrícula (visita → seguir) |
| ¿Se queda? | visto medio / duración · skip | Gancho (skip) y cuerpo (visto medio) |
| ¿Se mueve? | envíos / 1.000 · guardados / 1.000 | Distribución futura |

Con muestra pequeña: **medianas**, nunca medias (un viral las rompe).
