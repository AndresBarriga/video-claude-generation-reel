# Recurso gratis · Test «Vas de primero, vas petado. ¿Chapas bien?» (V1)
- **Qué es:** una página (`index.html`, ~0,9 MB, sin dependencias ni backend ni email) con 9 escenas de chapaje, nota al final, chuleta descargable (PNG) y botón de compartir. Dibujos del kit (E59/E64/E72) renderizados a SVG.
- **Generar:** `npm run test-chapaje` (lee `escenas.ts` + `plantilla.html` → `index.html`). Textos y respuestas en `escenas.ts`; dibujos en `build.tsx`.
- **Interacción (3 patrones):** elegir entre dos (1, 3, 7, 8, 9) · tocar en el dibujo (2, 4, 6) · girar el mosquetón y comprobar (5).
- **Captación:** comentario fijado en E59 y E64 (y pie del próximo vídeo de chapar): «Comenta TEST…» → Meta Business Suite, Comment to message (variantes TEST/test/Test) → DM con el enlace. Probar antes desde otra cuenta con frases («quiero el test»).
- **Alojamiento:** Netlify Drop (arrastrar la carpeta con `index.html`), URL anónima tipo `ultimopegue.netlify.app`. No GitHub Pages de esta cuenta (nombre real y expondría el dashboard).
